As imagens SVG e seus comportamentos são definidos em arquivos de texto XML, o que significa que podem ser pesquisados, indexados, programados e compactados. Os arquivos SVG podem ser convertidos em formatos Visio usando Aspose.Diagram for Java, permitindo que gráficos vetoriais sejam trazidos para o ecossistema Microsoft Visio.
